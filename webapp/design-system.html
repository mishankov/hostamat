Design Principles

Bold & Unapologetic

High contrast colors, thick borders, and strong shadows create visual impact. Every element demands attention and serves a clear purpose.

Functional Brutality

Form follows function with raw, honest design. No unnecessary decorations - every visual element has a functional purpose.

Precise Alignment

Clean, grid-based layouts with perfect alignment create order within the bold aesthetic. Every element has its place and purpose.

Accessibility First

High contrast ratios ensure readability. Bold design doesn't compromise usability - it enhances it through clear visual hierarchy.

Implementation Guidelines

CSS Custom Properties

Use the CSS custom properties (variables) defined in :root for consistent theming. This allows for easy customization and theme switching.

Component Modifiers

Combine base classes with modifier classes for variations. For example: .btn.btn-primary or .card.bg-yellow

Responsive Behavior

Grid layouts automatically stack on mobile devices. Navigation collapses to vertical layout. Always test on multiple screen sizes.

Animation Guidelines

Keep transitions short (0.2s) and purposeful. Use transform properties for performance. Avoid excessive animation that detracts from usability.

Color Usage

Use bright accent colors sparingly for CTAs and alerts. Black/white should dominate the layout with pops of color for emphasis and hierarchy.
